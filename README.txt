ENGLISH TRAIN – eigene Lern-App

Inhalt:
- 200 Karten Bulgarisch -> Englisch
- 15-Minuten-Sessions
- 'Gelernt' / 'Noch lernen'
- automatische Wiederholung
- englische Sprachausgabe
- Lernstand lokal auf dem Gerät
- nach Installation offline nutzbar

Wichtig:
Eine PWA muss über HTTPS/Webserver geöffnet werden. Eine lokale HTML-Datei in der iPhone-Dateivorschau ist nicht dasselbe.
