ENGLISH TRAIN – WORD STATUS + VERB DRILL

NEW LOGIC
- Every card starts with a Bulgarian sentence.
- The Bulgarian target word/expression is red.
- After flipping, the English target word/form is red.
- "Learned" refers to the TARGET WORD, not to the whole sentence.
- If a later repetition is marked "Learn again", that word leaves Learned.
- Mastered is reached only through later successful repetitions, not merely because several fresh tense cards of the same verb were shown.
- Audio always reads the complete English sentence.

VERB DRILL
- New category: Verb Drill
- 50 frequent irregular verbs
- 7 cards per verb, presented consecutively on first exposure:
  1. Present Simple
  2. Past Simple
  3. Present Perfect
  4. Past Perfect
  5. Future Simple
  6. Conditional
  7. Should Have
- English side always shows all 3 irregular forms, e.g. go – went – gone.
- Tense name is shown on the card.
- Drill sentences are intentionally very short.

EXAMPLE
Аз отивам вкъщи. -> I go home.
Аз отидох вкъщи. -> I went home.
Аз съм отишла вкъщи. -> I have gone home.
Аз бях отишла вкъщи. -> I had gone home.
Аз ще отида вкъщи. -> I will go home.
Аз бих отишла вкъщи. -> I would go home.
Трябваше да отида вкъщи. -> I should have gone home.

STATISTICS
- Existing card history is preserved in local storage.
- A one-time migration converts the visible Learned/Mastered counters to word-based statistics.
- NEW and Verb Drill share the same irregular-verb word status because they train the same vocabulary.
